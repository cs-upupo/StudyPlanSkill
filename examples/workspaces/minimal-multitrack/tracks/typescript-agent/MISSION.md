# Mission: TypeScript Agent

## 为什么学

用 TypeScript 理解和实现一个最小 AI Agent 执行链路，而不是只看语法教程。

## 成功标准

能够解释并实现：

- 用户输入如何进入 Agent。
- tool schema 如何定义。
- tool call 如何执行。
- 执行结果如何回到模型或下一步逻辑。

完成一个能运行的最小 tool call demo，并能用自己的话解释每一步。

## 现实约束

- 先用最小 demo 暴露 TypeScript 和 Agent 执行链路卡点。
- 不先引入完整 Agent 框架。

## 暂不学习

- 暂不展开多工具编排、长期记忆、复杂框架源码和生产级部署。
